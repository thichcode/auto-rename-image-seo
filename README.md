# Auto Rename Image SEO

A tiny plugin that automatically renames your image files on upload to SEO-friendly filenames based on your post title.

## Problem Solved
- Improve search rankings with descriptive image filenames instead of `IMG_1234.jpg`
- Zero manual work — runs automatically on every upload
- Increases chances that your images appear in Google Images and other search engines

## Features
- ✅ Rename images on upload to **post-title-image-1.jpg**
- ✅ Works with posts, pages, custom post types
- ✅ Compatible with WooCommerce products
- ✅ Free Lite: 20 renames/week
- ✅ Pro: Unlimited renames for $2 one-time license
- ✅ Zero configuration — install & forget
- ✅ Under 300 lines of clean PHP
- ✅ GDPR compliant — no external API calls
- ✅ Compatible WordPress 6.x + PHP 8.1

## How to Use
1. Upload plugin ZIP in WordPress admin → Plugins → Add New
2. Activate the plugin
3. Upload images to any post or page
4. Plugin automatically renames the files
