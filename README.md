# Auto Rename Image SEO

Tiny WordPress plugin that renames new image uploads into SEO-friendly filenames.

## Features
- Rename new image uploads before WordPress saves them
- Optional site name/date in filename
- Lite monthly limit: 20 renames
- Pro license field for $2 unlock
- Secure admin page with nonce/capability checks
- Uninstall cleanup

## Manual test
1. Install ZIP
2. Activate plugin
3. Visit Settings > Auto Rename Image SEO
4. Upload `IMG_1234.JPG`
5. Confirm Media Library filename becomes slug-like
6. Save settings, verify nonce/capability flow
7. Uninstall, verify options removed
