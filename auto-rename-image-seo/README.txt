Automatically renames uploaded image files into SEO-friendly filenames.

== Description ==

Auto Rename Image SEO fixes messy image filenames like IMG_1234.jpg by renaming new image uploads into clean SEO slugs before WordPress saves them.

Lite mode includes 20 renames per month. Pro unlocks unlimited renames with a license key field.

== Installation ==

1. Upload the plugin ZIP in Plugins > Add New.
2. Activate Auto Rename Image SEO.
3. Open Settings > Auto Rename Image SEO.
4. Choose filename options.

== Frequently Asked Questions ==

= Does it rename existing images? =
No. It only renames new uploads to avoid broken old URLs.

= Does it change image alt text? =
No. It only changes filenames.
